# 驗證目錄 — 演算法效力的可複驗證據

本目錄的腳本用來**證明或推翻**雷達各指標的有效性。任何人都能獨立重跑，
得到與 UI「資料可信度」分頁完全一致的數字。

```bash
cd validation
py v1_attention.py    # 注意力指標效力（方向性 vs 波動性）
py v2_divergence.py   # KL 散度門檻：舊法凍結診斷 + 新舊法效力對比
py v3_data_audit.py   # 資料源稽核：完整度、異常值、point-in-time
py v4_regression.py   # 新舊警報規則的迴歸差異
```

資料來源為 `../docs/data.js`（線上實際使用的同一份）。

---

## 方法論：五條嚴格性原則

所有檢定共用，寫在 `common.py`：

1. **無前視偏誤** — 任何 t 時點的指標只能用 ≤ t 的資料。
   （已修掉一個實例：`kl_series` 原本用全期間 tone 算分箱邊界）
2. **事件去重** — 連續突破只計首次，避免同一事件灌水膨脹樣本數。
3. **對照組明確** — 事件組 vs 非事件組，而非事件組 vs 全體（後者含事件本身）。
4. **置換檢定** — 不假設常態分布。把事件日隨機打散 10000 次，
   看真實觀測值在虛無分布中有多罕見。每資產抽樣數與真實事件數一致，
   避免資產組成偏移污染虛無分布。
5. **多重比較校正** — 同時測 3 閾值 × 5 期間 = 15 組時，用 Benjamini-Hochberg
   控制偽發現率。未校正的單次 p<0.05 在 15 組中約有 54% 機率純屬巧合。

## 結論摘要（2026-08-15，樣本 5 資產 × 362 天）

### 注意力指數 attn_z — 有效，但只在一個方向上

| 假設 | 結果 |
|---|---|
| H1 預測漲跌方向 | **15 組檢定全數未通過**。z>2.5 的 1D 未校正 p=0.027，BH-FDR 校正後不成立 |
| H2 預測波動放大 | **z≥2.5 時 1D/3D/5D/10D 全數通過**（p=0.001~0.016） |

z>2.5 的波動放大倍數：1D 1.79x／3D 1.47x／5D 1.33x／10D 1.35x，20D 失效（p≈0.58）。

**警戒值由 2.0 上調為 2.5 的依據**：z>2.0 僅 1D 通過，3D（p=0.057）與 5D（p=0.110）
皆不顯著。迴歸測試進一步證實被濾掉的 2.0~2.5 弱訊號 **3D 放大倍數僅 1.00x**
（等於完全無訊號），而保留的強訊號為 1.47x。這是精準切除雜訊，不是丟失資訊。

### KL 散度 — 無統計顯著性，已降級為觀察指標

| 門檻法 | 1D | 3D | 5D |
|---|---|---|---|
| 舊 `rolling(180).q95` | 1.23x (p=0.21) | 1.10x (p=0.30) | 1.17x (p=0.21) |
| 新 `EWM(90)+2sd` | 0.98x (p=0.50) | 0.91x (p=0.65) | 1.02x (p=0.43) |

兩法皆未達顯著。**修門檻救不回一個本身沒有訊號的指標**，故停止以此發送警報，
僅保留圖表供人工觀察敘事結構變化。

附帶修掉的工程缺陷：舊門檻會**凍結**。分位數是「排序取位置」，一批極值只要
還在 180 天窗內，95 分位就固定在同一數值。實測 XAU 最長連續凍結 **92 天**
（值 1.1280），期間 KL 實際只在 0.13~0.69 遊走，門檻形同虛設。
五個資產凍結比例 36~46%。新法每日更新，凍結比例 0%。

### 散度方向 — 找到病因，但樣本不足以認定訊號

KL 是純量：敘事「轉樂觀」與「轉悲觀」得分相同，價格意涵卻相反。方向被丟棄，
等於把兩種相反情境混在一起互相抵消——這是它測不出訊號的主因之一。

加回方向後（`v6_signed_kl.py`），突破後報酬：

| 期間 | 轉悲觀 | 轉樂觀 | 差距 | 置換檢定 p |
|---|---|---|---|---|
| 1D | −0.38% (n=10) | +0.96% (n=8) | −1.34% | 0.116 不顯著 |
| 3D | +1.46% | −0.07% | +1.53% | 0.223 不顯著 |
| 5D | +2.63% | −1.10% | +3.73% | **0.048 顯著** |
| 10D | +1.77% | +0.92% | +0.85% | 0.735 不顯著 |

**判定：不足以認定為可用訊號。** 真訊號應如 attn_z 那樣多期間一致顯著，
此處僅 5D 單點過線、樣本僅 8~10 次，且測了 4 個期間未做多重比較校正——
校正後 5D 亦不成立。故 UI 只陳述方向事實，不做多空解讀。

另已排除的假設：縮短觀測窗（`v5_kl_diag.py` P2）。3/5/7/14 天窗全部不顯著
（p=0.23~0.55），排除「訊號被 7 天窗平滑掉」這條路。

### 訊號有效期 — D+1 ~ D+5

事件後單日波動 / 常態單日波動：

```
D+0 1.75x  D+1 1.38x  D+2 1.20x  D+3 1.19x  D+4 1.06x  ...  D+8 1.01x
```

單調衰減至 D+4 回歸常態，D+8 後與常態無異。故建議回檢時點 **D+1 / D+3 / D+5**。
（D+13~D+14 有一個 1.4~1.5x 的反彈，但非單調、樣本小、無機制解釋，判定為雜訊。）

## 已知限制

- **樣本僅一年**（約 360 天），事件數 30~60 次，屬小樣本。結論會隨資料累積修正。
- GDELT 只涵蓋公開網路新聞，不含社群媒體與私有終端。
- 語調為英文語料模型，中文報導未納入。
- 五個資產中三個是美股大型科技股，彼此相關性高，實質獨立樣本數少於名目值。

## 建議的後續驗證

1. 資料累積到兩年後重跑全部檢定，確認結論穩定性。
2. 加入 sample-split：前半年校準閾值、後半年做樣本外驗證。
3. 波動放大訊號可對照選擇權隱含波動率（IV），檢驗是否已被市場定價。
